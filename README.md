# HARMONEY

Harmoney est une application de gestion de finances. On peut suivre ses dépenses quotidiennes, budgétiser ses revenus en pourcentage en corrélation à la mise en place d'un pourcentage d'épargne et avoir un oeil sur ses charges mensuelles, variables comme fixes.
